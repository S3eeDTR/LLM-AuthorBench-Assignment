BENCHMARK TEST EXAMPLES

One original, unedited C program per recorded generator label.
Selection rule: first test row in the saved splits.csv for each label.
No classifier predictions were consulted to choose these examples.
These are held-out benchmark examples, not new independent evaluation data.

In the platform, click Open .c file and choose one of the five .c files.
Choose Compare both models. Test with Keep as pasted, then Remove before analysis.
The filename and sample_manifest.json give the dataset's recorded generator label.
The label is metadata; it is not included in the code submitted to the classifier.
Programs are preserved exactly, including comments and any original flaws.
Do not run them to test attribution: the platform only reads their source text.
Some programs exceed 512 tokens, so the platform will show its truncation warning.

Source: https://github.com/LLMauthorbench/LLMauthorbench
Split: https://github.com/S3eeDTR/LLM-AuthorBench-Assignment/blob/main/data/splits.csv
